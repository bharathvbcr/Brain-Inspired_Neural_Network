# BINN claim-axis taxonomy (A0)

Every scientific arm and result note must carry these four fields in the header:

```
claim_axis: Novel-CS | Brain-motif-under-test | Integrity
object_under_test: <one sentence>
may_claim: <narrow sentence>
must_not_claim: <brain / impossibility / remassage / ...>
```

---

## Axes

### Novel-CS

**Meaning:** Algorithmic / credit / substrate **engineering** claim under a preregistered gate.

**May claim:** Named protocol + hash cleared (or failed) an operationalized accuracy/gap bar on a disclosed forward.

**Must not claim:** Biology, cortex, neuromorphic HW validation, impossibility in principle.

**Examples:** matched broadcast FAIL (v4); matched DFA/RL PASS (v5/v12); live RFB transfer FAIL (v13–v19); break-it **v20 / v21 / v24**.

### Brain-motif-under-test

**Meaning:** A biological *motif* is exercised in the harness (three-factor algebra, assemblies, neuromodulators, dendrites, spikes).

**May claim:** Motif was present / exercised / failed-or-unused **under this harness**. A FAIL is “motif-under-this-harness negative.” A PASS is “motif-sufficient-here.”

**Must not claim:** “We built a brain,” “proves cortex,” “biology is wrong,” Assembly Calculus PASS on canonical C1.

**Examples:** natural spikes (D13), AC `project` (D14), dendrites on C1 path (D16), three-factor STDP algebra presence.

### Integrity

**Meaning:** Confounder isolation, adversarial undertraining, harness honesty. Supports trust; **not** a product claim.

**May claim:** Named confounder was isolated under a new hash; verdict PASS/FAIL/INVALID_HARNESS with disclosed knobs.

**Must not claim:** Product superiority from integrity arms alone; silent threshold massage of closed hashes.

**Examples:** H1/H2 isolation; dual-gap disclosure; **v22** undertrain; **v23** finite-θ under SFB; elig ceiling; nominal sparsity.
